## 📖 Overview

The **Library Management System** is a desktop application developed to simplify library operations through an intuitive graphical user interface.

It enables librarians to manage books, students, and borrowing transactions efficiently while demonstrating practical implementation of **Object-Oriented Programming**, **JDBC connectivity**, and **MySQL database integration**.

# 🗄 Database Schema

The application uses **MySQL** as the backend database.

### Tables

| Table | Description |
|--------|-------------|
| Books | Stores books information |
| Students | Stores student records |
| Librarians | Stores librarian information |
| Transactions | Stores issue & return records |

- Eclipse
