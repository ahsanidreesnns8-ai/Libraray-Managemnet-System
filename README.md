#  Library Management System

A Java-based **Library Management System** developed using **Object-Oriented Programming (OOP)** concepts with **Java Swing** for the graphical user interface and **MySQL** for database management.

The project allows librarians to efficiently manage books, students, and book transactions through a simple and user-friendly interface.

---

##  Features

-  Add Books
-  View Books
-  Search Books
-  Update Book Details
-  Delete Books
-  Register Students
-  View Students
-  Search Students
-  Issue Books
-  Return Books
-  View Issued Books
-  Generate Basic Reports
-  MySQL Database Integration

##  Database

The project uses **MySQL** as the backend database.

Main tables include:

- Books
- Students
- Librarians
- Transactions

---

##  How to Run

1. Clone the repository.
2. Create the `librarydb` database in MySQL.
3. Import or create the required tables.
4. Update the database username and password in `DatabaseManager.java`.
5. Add the MySQL Connector/J library to the project.
6. Run `Library_Management_System.java`.
